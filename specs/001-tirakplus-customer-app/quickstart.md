
# Quickstart Validation: Tirak Plus Customer App

## Prerequisites

- Read .specify/memory/constitution.md.
- Read DESIGN.md.
- Read docs/design/responsive-view-matrix.md.
- Read docs/issues/backlog-map.md for the relevant issue IDs.

## Validation Flow

1. Confirm no unresolved clarification markers exist in spec.md, plan.md, tasks.md, contracts, or shared docs.
2. Confirm staged data is requested through documented API routes, not UI component arrays.
3. Check required breakpoints: mobile 390x844, tablet 768x1024, desktop 1280x800, wide 1440x900.
4. Run visual QA against the anti-pattern gate.
5. Attach evidence to the relevant issue.

## Smoke Scenarios

- Visitor opens home and chooses traveller path.
- Traveller filters discovery by Bangkok and Muay Thai night.
- Traveller opens a companion profile and submits an inquiry.
- Companion resumes onboarding, edits visibility, updates availability, and submits verification.
- User opens safety center and account/privacy settings.
