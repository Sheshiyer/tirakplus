# Responsive View Matrix

This matrix is binding for Tirak Plus customer and admin design work. Every planned screen must be reviewed at the four viewport sizes below before implementation is marked ready.

- Mobile 390x844: single column, bottom-safe actions, 44px minimum touch targets, no horizontal overflow.
- Tablet 768x1024: two-column where useful, persistent contextual panels only when content remains readable.
- Desktop 1280x800: asymmetric editorial layout, constrained content width, full nav, side panels for filters/review.
- Wide desktop 1440x900: max-width locked near 1400px, gutters absorb excess width, no over-stretched cards.


## Home

| Viewport | Required layout | Critical checks |
|---|---|---|
| Mobile 390x844 | Single-column, bottom-safe primary action, filters/actions in bottom sheet or stacked sections. | No horizontal overflow; 44px touch targets; no text over active imagery. |
| Tablet 768x1024 | Two-column where useful; list/detail pattern allowed for operational surfaces. | Panels remain readable; no cramped card grids; keyboard does not hide form actions. |
| Desktop 1280x800 | Full navigation and asymmetric layout; side rails allowed for filters or context. | Content max width honored; primary action hierarchy is clear. |
| Wide 1440x900 | Same structure as desktop with gutters absorbing width and no stretched cards. | Cards do not over-expand; admin tables add useful columns only. |

Design gate: Must satisfy DESIGN.md and the anti-pattern checklist before implementation.
